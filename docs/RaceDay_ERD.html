RaceDay Entity Relationship Diagram

Primary keys (PK), foreign keys (FK), attributes and relationship cardinality.

Users

  • PK UserId : int
  • FullName : nvarchar(100)
  • Email : nvarchar(255) UNIQUE
  • PasswordHash : nvarchar(255)
  • Role : varchar(20)
  • PhoneNumber : nvarchar(30)
  • CreatedAt : datetime2

Events

  • PK EventId : int
  • FK OrganiserId : int → Users
  • Name : nvarchar(150)
  • Description : nvarchar(1000)
  • EventDate : datetime2
  • Venue : nvarchar(200)
  • Status : varchar(20)

Categories

  • PK CategoryId : int
  • FK EventId : int → Events
  • Name : nvarchar(100)
  • DistanceKm : decimal(5,2)
  • EntryFee : decimal(10,2)
  • Capacity : int

Enrolments

  • PK EnrolmentId : int
  • FK ParticipantId : int → Users
  • FK CategoryId : int → Categories
  • BibNumber : int
  • EnrolledAt : datetime2
  • Status : varchar(20)

Results

  • PK ResultId : int
  • FK EnrolmentId : int UNIQUE
  • FinishTimeSeconds : int
  • Position : int
  • ResultStatus : varchar(10)
  • RecordedAt : datetime2

Payments

  • PK PaymentId : int
  • FK EnrolmentId : int UNIQUE
  • Amount : decimal(10,2)
  • PaymentReference : nvarchar(80) UNIQUE
  • PaymentStatus : varchar(20)
  • PaidAt : datetime2 NULL

Relationships and cardinality

  • Users (Organiser) 1 → 0..* Events — an organiser creates events; each event has one organiser.
  • Events 1 → 1..* Categories — an event contains one or more categories; each category belongs to one event.
  • Users (Participant) 1 → 0..* Enrolments — a participant may have many enrolments; each enrolment belongs to one participant.
  • Categories 1 → 0..* Enrolments — a category may have many enrolments; each enrolment is for one category.
  • Enrolments 1 → 0..1 Results — an enrolment may produce zero or one result; each result is for one enrolment.
  • Enrolments 1 → 0..1 Payments — an enrolment may have zero or one payment; each payment is for one enrolment.
Many-to-many resolution: Participants and categories are many-to-many conceptually; Enrolments is the associative entity that resolves it.
